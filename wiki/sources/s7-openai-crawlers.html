重點

  1. OpenAI 提供四種獨立爬蟲/用戶代理，分別用於搜尋、廣告驗證、模型訓練與用戶即時請求 [S7]。
  2. OAI-SearchBot 控制 ChatGPT 搜尋結果顯示，GPTBot 控制是否用於基礎模型訓練，兩者可獨立設定 [S7]。
  3. ChatGPT-User 由用戶動作觸發，非自動爬取，robots.txt 規則可能不適用 [S7]。
  4. OpenAI 發布各爬蟲 IP 範圍 JSON 供驗證，若同時開放 OAI-SearchBot 與 GPTBot 可能合併爬取避免重複 [S7]。
  5. robots.txt 更新約需 24 小時生效於 OpenAI 系統 [S7]。

作者或文件自述限制

  1. User-Agent 版本號可能變更：文件明確標示版本號可能變更，網站管理者不應依賴特定版本號進行識別 [S7]。
  2. IP 範圍 JSON 為發布時點快照：OpenAI 發布 IP 範圍 JSON 供驗證，但未說明更新頻率與通知機制 [S7]。
  3. ChatGPT-User robots.txt 可能不適用：文件明確說明「Because these actions are initiated by a user, robots.txt rules may not apply」[S7]。
  4. 合併爬取為可能而非保證：「we may use the results from just one crawl」表示視情況合併，非強制 [S7]。
  5. ~24 小時為估算值：robots.txt 更新生效時間標示為「~24 hours」，非精確承諾 [S7]。
  6. 僅代表 OpenAI 平台：不代表 Google、Perplexity 等其他 AI 平台的爬蟲行為 [S7]。

對校園網站 GEO 的意義（推論）

  • 搜尋能見度與訓練授權分離：政大可允許 OAI-SearchBot 讓招生內容出現在 ChatGPT 搜尋結果，同時封鎖 GPTBot 表示不授權內容用於模型訓練（推論，基於 S7 獨立控制說明）[S7]。
  • ChatGPT-User 需基礎設施層放行：因 robots.txt 可能不適用，政大需確認 CDN/WAF 未封鎖 ChatGPT-User 的 IP 範圍與 User-Agent，確保用戶即時請求能取得內容（推論，基於 S7 robots.txt 可能不適用）[S7]。
  • IP 範圍驗證機制：政大可定期下載 OpenAI 發布的 IP 範圍 JSON（searchbot.json、gptbot.json、adsbot.json、chatgpt-user.json）更新防火牆白名單（推論，基於 S7 Published IP addresses）[S7]。
  • ~24 小時生效時間納入驗證清單：robots.txt 變更後需等待約 24 小時才能在 OpenAI 系統生效，上線驗證需預留時間（推論，基於 S7 ~24 hours）[S7]。
  • OAI-AdsBot 僅廣告落地頁驗證：若政大未在 ChatGPT 投放廣告，OAI-AdsBot 存取頻率極低，可視情況開放（推論，基於 S7 OAI-AdsBot 用途）[S7]。
