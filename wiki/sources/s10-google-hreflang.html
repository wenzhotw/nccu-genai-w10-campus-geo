S10｜hreflang

來源：S10 - Tell Google about localized versions of your page

基本資料

  • 標題：Tell Google about localized versions of your page
  • 發布單位：Google Search Central（Google 官方開發者文件）
  • URL：https://developers.google.com/search/docs/specialty/international/localized-versions
  • 來源類型：平台官方技術文件
  • 頁面日期（page_date）：2026-09-21 UTC [S10]
  • 擷取日期（fetched_at）：2026-11-22 11:32:53 CST [S10]
  • HTTP 狀態碼：200 [S10]
  • 來源檔案大小：201219 bytes [S10]
  • SHA256：d26b29d5e83dbd2cc082847ab4f7dc238ea526530b647895157675b4b3d44f94 [S10]
  • 適用範圍：Google 搜尋官方文件，說明如何透過 hreflang（HTML link 標籤、HTTP Header、Sitemap）告知 Google 多語言/多地區頁面版本，適用於國際化網站的語言與地區導向設定。

重點

  1. 提供三種等效方法標示替代頁面：HTML link 標籤、HTTP Header、XML Sitemap，三選一即可，同時使用無額外搜尋效益 [S10]。
  2. 每個語言版本必須列出自身以及所有其他語言版本，且需雙向連結，否則標記會被忽略 [S10]。
  3. 替代網址必須為完整合格網址（含 http/https），不可使用相對路徑 [S10]。
  4. 保留值 x-default 用於無符合語言/地區時的回退頁面，建議用於語言選擇頁 [S10]。
  5. 常見錯誤包含缺少回連結、語言代碼錯誤（需符合 ISO 639-1）、地區代碼錯誤（需符合 ISO 3166-1 Alpha 2） [S10]。
  6. Google 不使用 hreflang 或 HTML lang 屬性偵測頁面語言，而是演算法判斷 [S10]。（G1 核對未找到 verbatim “Google doesn’t use hreflang or the HTML lang attribute to detect the language of”，標記待查）

作者或文件自述限制

  1. 僅代表 Google 搜尋官方立場：不代表其他搜尋引擎或生成式 AI 系統的運作方式 [S10]。
  2. 索引與顯示不保證：符合所有需求、最佳實踐與政策，不代表 Google 會爬取、索引或顯示內容 [S10]。
  3. 第三方除錯工具非 Google 維護：文件列出的 Aleyda Solis、Merkle SEO 工具非 Google 官方，可靠度待查 [S10]。
  4. 文件未涵蓋生成式 AI 功能：未說明 hreflang 對 AI Overviews、AI Mode 等生成式 AI 功能的具體影響 [S10]。

與其他來源的關係

  • S2（Google 生成式 AI 指南）：S2 指出 SEO 最佳實踐仍適用於生成式 AI 搜尋；S10 為國際化 SEO 技術規範，兩者互補 [S2][S10]。
  • S3（Google AI 功能）：S3 確認 query fan-out 機制；S10 的 hreflang 設定可能影響子查詢的語言版本匹配（推論，待查）[S3][S10]。
  • S8（學生前期研究）：S8 規劃政大國際招生網站多語言分兩階段（en/zh-Hant/ja → ko/vi/id），需依 S10 部署 hreflang 雙向連結與 x-default [S8][S10]。
  • S8（學生前期研究）：S10 寫明兩頁要互相指向，否則標記會被忽略（”If two pages don’t both point to each other, the tags will be ignored”）；S8 規格寫「每頁的 都要放互相對應的 hreflang」，方向一致，不是矛盾，見 open-questions 矛盾第 8 條 [S10][S8]。

對校園網站 GEO 的意義（推論）

  • 多語言部署技術基礎：政大國際招生網站規劃 en/zh-Hant/ja 第一階段、ko/vi/id 第二階段，必須依 S10 正確部署 hreflang（HTML link、HTTP Header 或 Sitemap 三選一），確保 Google 正確導向對應語言版本（推論，基於 S10、S8）[S10][S8]。
  • 雙向連結強制性：每個語言版本必須列出自身與所有其他版本且雙向連結，否則標記被忽略；CMS 需自動化產生完整 hreflang 集合，避免人工疏漏（推論，基於 S10）[S10]。
  • x-default 回退策略：建議在語言選擇頁或首頁設定 x-default，處理無符合語言的使用者，符合政大多語言入口頁設計（推論，基於 S10）[S10]。
  • 語言/地區代碼合規：需嚴格遵循 ISO 639-1（語言）、ISO 3166-1 Alpha 2（地區）、ISO 15924（腳本），如 zh-Hant、zh-Hans、en-US、ja-JP、ko-KR、vi-VN、id-ID 等（推論，基於 S10）[S10]。
  • 生成式 AI 影響未知：S10 未提及 hreflang 對 AI Overviews、AI Mode 的影響；query fan-out 機制下子查詢如何匹配語言版本待查（推論，基於 S3、S10）[S3][S10]。

待查

  1. Google 不使用 hreflang 或 HTML lang 屬性偵測頁面語言的 verbatim 確切位置（G1 核對未找到 “Google doesn’t use hreflang or the HTML lang attribute to detect the language of”，標記待查）[S10]。
  2. x-default value verbatim 確切位置（G1 核對未找到 “x-default value”，標記待查）[S10]。
  3. hreflang 對 Google 生成式 AI 功能（AI Overviews、AI Mode）的具體影響，文件未提及 [S10]。
  4. x-default 頁面在生成式 AI 回應中的顯示邏輯 [S10]。
  5. 多語言網站在 query fan-out 機制下，子查詢如何匹配語言版本 [S10][S3]。
  6. 文件提及的第三方除錯工具（Aleyda Solis、Merkle SEO）非 Google 維護，可靠度待查 [S10]。
  7. 「If it becomes difficult to maintain a complete set of bidirectional links for every language, you can omit some languages on some pages」的實際容忍度與邊界條件 [S10]。
