重點

  1. PerplexityBot 用於搜尋結果呈現與連結，不作為 AI 基礎模型訓練爬蟲 [S9]。
  2. Perplexity-User 由用戶即時請求觸發，非自動爬取，一般忽略 robots.txt 規則 [S9]。
  3. 兩種爬蟲皆發布 IP 範圍 JSON 端點，供防火牆白名單驗證 [S9]。
  4. WAF 設定建議結合 User-Agent 比對與 IP 範圍驗證，確保合法流量通行 [S9]。
  5. 提供 Cloudflare WAF 與 AWS WAF 具體設定步驟與規則範例 [S9]。

對校園網站 GEO 的意義（推論）

  • 搜尋能見度與用戶即時存取分離：政大可允許 PerplexityBot 讓招生內容出現在 Perplexity 搜尋結果，同時需在基礎設施層（CDN/WAF）放行 Perplexity-User IP 範圍以支援用戶即時請求（推論，基於 S9 兩種代理用途區分）[S9]。
  • robots.txt 不足以控制 Perplexity-User：因 Perplexity-User 一般忽略 robots.txt，政大需確認 CDN/WAF/防火牆未封鎖其 IP 範圍與 User-Agent，確保用戶即時請求能取得內容（推論，基於 S9 robots.txt 行為說明）[S9]。
  • IP 範圍驗證機制：政大可定期下載 Perplexity 發布的 IP 範圍 JSON（perplexitybot.json、perplexity-user.json）更新防火牆白名單（推論，基於 S9 Published IP addresses）[S9]。
  • WAF 設定參考：可依 S9 提供的 Cloudflare WAF 與 AWS WAF 範例配置規則，結合 User-Agent 比對與 IP 範圍驗證（推論，基於 S9 WAF Configuration）[S9]。

待查

  1. PerplexityBot 是否完全遵循 robots.txt（文件僅建議允許，未明確聲明遵循）[S9]。
  2. IP 範圍 JSON 更新頻率與通知機制（文件未說明）[S9]。
  3. Perplexity-User 實際上是否完全忽略 robots.txt，還是部分遵循 [S9]。
  4. User-Agent 版本號變更頻率與向後相容性 [S9]。
