概念：AI 爬蟲與 robots 設定

一句話定義

控制 AI 爬蟲（如 Google-Extended、OAI-SearchBot、GPTBot、PerplexityBot 等）存取網站內容的技術設定，包含 robots.txt 規則、HTTP 標頭、防火牆/CDN 設定，確保關鍵內容可被索引並用於生成式 AI 回應。

重點

  1. 主要 AI 爬蟲 User-Agent：
    - Google：Googlebot（Google 搜尋的爬取與存取，含搜尋中的 AI 功能）[S3]；Google-Extended（管理內容在部分 Google 其他系統中的訓練與 grounding；「doesn’t affect Google Search」）[S3][S5]
    - OpenAI：OAI-SearchBot（搜尋檢索）、GPTBot（模型訓練）、ChatGPT-User（用戶即時請求）、OAI-AdsBot（廣告落地頁驗證）[S7]
    - Perplexity：PerplexityBot（索引）、Perplexity-User（用戶即時請求）[S9]
  2. Google 官方指引（S2、S3、S5）：
    - 重要內容必須為 HTML 文字，才能被生成式 AI 系統理解與引用[S2][S3]。
    - robots.txt 指令控制 Googlebot 爬取是網站擁有者管理搜尋存取的方式[S3]。
    - robots.txt 之外，CDN 或主機設施也要允許抓取（原文：「Ensuring that crawling is allowed in robots.txt, and by any CDN or hosting infrastructure」）[S3]。
    - 網站必須在 Search Console 具備「included in Search generative AI features」資格，才能在生成式 AI 功能中顯示[S2]。
    - Google-Extended：2023-09-28 新增權杖，供網站管理內容是否用於改進 Bard／Vertex AI 生成式 API [S5]。S5 於 2024-02-08 寫明 “Google-Extended doesn’t affect Google Search” [S5]。S3：限制「AI training and grounding in some of Google’s other systems」時才看 Google-Extended；搜尋（含 AI 功能）仍用 Googlebot 與 snippet／noindex 等控制 [S3]。
    - 重新抓取時間：S3 寫預覽控制變更後，「crawling can take anywhere from several days to several months」[S3]。OpenAI 約 24 小時生效 [S7]。
  3. OpenAI 官方文件（S7）：
    - OAI-SearchBot 用於 ChatGPT 搜尋功能檢索，允許則內容可能出現在搜尋答案中 [S7]。
    - GPTBot 用於基礎模型訓練，禁止則表示內容不應用於訓練 [S7]。
    - OAI-SearchBot 與 GPTBot 設定獨立，可分別允許或禁止 [S7]。
    - 若同時開放兩者，OpenAI 可能合併爬取避免重複 [S7]。
    - ChatGPT-User 由用戶動作觸發，非自動爬取，robots.txt 規則可能不適用 [S7]。
    - OAI-AdsBot 僅驗證廣告落地頁，不參與模型訓練 [S7]。
    - 各爬蟲發布 IP 範圍 JSON 供驗證：searchbot.json、gptbot.json、adsbot.json、chatgpt-user.json [S7]。
    - robots.txt 更新約需 24 小時生效於 OpenAI 系統 [S7]。
  4. Perplexity 官方文件（S9）：
    - PerplexityBot 用於搜尋結果呈現與連結，不作為 AI 基礎模型訓練爬蟲，建議在 robots.txt 允許 [S9]。
    - Perplexity-User 由用戶即時請求觸發，非自動爬取，一般忽略 robots.txt 規則 [S9]。
    - 兩種爬蟲皆發布 IP 範圍 JSON 端點：perplexitybot.json、perplexity-user.json [S9]。
    - WAF 設定建議結合 User-Agent 比對與 IP 範圍驗證，提供 Cloudflare WAF 與 AWS WAF 具體步驟 [S9]。
  5. 國際化多語言導向（S10）：
    - 透過 hreflang（HTML link 標籤、HTTP Header、Sitemap 三選一）告知 Google 多語言/多地區頁面版本 [S10]。
    - 每個語言版本必須列出自身以及所有其他語言版本，且需雙向連結，否則標記會被忽略 [S10]。
    - 替代網址必須為完整合格網址（含 http/https），不可使用相對路徑 [S10]。
    - 保留值 x-default 用於無符合語言/地區時的回退頁面，建議用於語言選擇頁 [S10]。
    - 常見錯誤包含缺少回連結、語言代碼錯誤（需符合 ISO 639-1）、地區代碼錯誤（需符合 ISO 3166-1 Alpha 2）[S10]。
    - Google 不使用 hreflang 或 HTML lang 屬性偵測頁面語言，而是演算法判斷（verbatim 待查）[S10]。
  6. 政大案例（S8）：robots.txt 開放 Googlebot、Google-Extended、OAI-SearchBot、GPTBot、ChatGPT-User、PerplexityBot、Perplexity-User；需請資訊單位確認 CDN/防火牆未擋攔[S8]。多語言分兩階段（en/zh-Hant/ja → ko/vi/id），需依 S10 部署 hreflang 雙向連結與 x-default[S8][S10]。
  7. 技術可及性檢查清單：
    - robots.txt 允許目標 User-Agent
    - 無 meta robots noindex/nofollow 阻擋關鍵頁面
    - 伺服器回應 200 OK，無 403/429/5xx
    - CDN/WAF/防火牆規則未封鎖已知 AI 爬蟲 IP 與 User-Agent
    - 重要內容為靜態 HTML 文字（非僅在 JavaScript 渲染後出現、非圖片/PDF 嵌入文字）[S2][S3][S8]
    - hreflang 正確部署：三選一實作、雙向連結完整、代碼符合 ISO 標準、x-default 設定 [S10]

張力或誤解

誤解/張力 說明
「robots.txt 開放就一定能被索引」 仍需符合搜尋技術需求、被索引、具備 Search Console 生成式 AI 功能資格；索引與顯示不保證[S2][S3]。
「封鎖 GPTBot 就能防止內容被訓練」 內容可能已被其他管道（Common Crawl、第三方資料集）收錄；封鎖僅影響未來爬取[S7]。
「Google-Extended 可以開關 Google 搜尋或 AI Overviews」 S3 把搜尋存取交給 Googlebot；Google-Extended 管的是其他系統的訓練與 grounding。S5（2024-02-08）寫明它 doesn’t affect Google Search [S3][S5]。
「PDF/圖片文字也能被 AI 讀取」 S2、S3 強調重要內容須為 HTML 文字；PDF/圖片文字可被索引但可及性較低，不建議作為關鍵資訊唯一載體[S2][S3]。
S7「ChatGPT-User robots.txt 可能不適用」vs S8「robots.txt 開放 ChatGPT-User」 S7 明確說明 ChatGPT-User 由用戶觸發，robots.txt 規則可能不適用；S8 仍在 robots.txt 中開放 ChatGPT-User。適用範圍：S7 為 OpenAI 官方文件說明機制限制；S8 為學生前期研究的實作選擇。見 open-questions 矛盾第 5 條。
S9「Perplexity-User 一般忽略 robots.txt」vs S8「robots.txt 開放 Perplexity-User」 S9 明確說明 Perplexity-User 由用戶觸發，一般忽略 robots.txt 規則；S8 仍在 robots.txt 中開放 Perplexity-User。適用範圍：S9 為 Perplexity 官方文件說明機制限制；S8 為學生前期研究的實作選擇。見 open-questions 矛盾第 5 條。
「hreflang 單向標就好」 S10 寫明兩頁要互相指向，否則標記會被忽略；S8 規格也要求「互相對應的 hreflang」。不是矛盾，見 open-questions 矛盾第 8 條 [S10][S8]。

本案怎麼用（政大國際招生網站）

  1. robots.txt 設定：允許 Googlebot、Google-Extended、OAI-SearchBot、GPTBot、ChatGPT-User、PerplexityBot、Perplexity-User；Disallow 僅針對管理後台、私密 API 等非公開路徑[S8]。
  2. 基礎設施確認：請資訊單位檢查 CDN（如 Cloudflare）、WAF、防火牆規則，確保未封鎖上述 User-Agent 或其 IP 範圍[S8]。
  3. 內容呈現：招生關鍵資訊（學程名稱、門檻、截止日期、獎學金金額、聯絡方式）均以 HTML 文字呈現，輔以 JSON-LD 結構化資料[S8]。
  4. Search Console 監測：驗證網站、確認「included in Search generative AI features」狀態、定期檢查索引覆蓋率報告[S2][S8]。
  5. 定期審查：每季檢查 robots.txt、伺服器日誌中的 AI 爬蟲存取情況、Search Console 索引狀態[S8]。
  6. OpenAI IP 範圍同步：定期下載 searchbot.json、gptbot.json、adsbot.json、chatgpt-user.json 更新防火牆白名單[S7]。
  7. Perplexity IP 範圍同步：定期下載 perplexitybot.json、perplexity-user.json 更新防火牆白名單[S9]。
  8. WAF 規則配置：參考 S9 提供的 Cloudflare WAF 與 AWS WAF 範例，結合 User-Agent 比對與 IP 範圍驗證，設定 Skip/Allow 規則並置於封鎖規則之前[S9]。
  9. hreflang 部署：採用 HTML link 標籤法（或 Sitemap 法），每語言版本列出自身與所有其他版本，確保雙向連結完整；代碼遵循 ISO 639-1、ISO 3166-1 Alpha 2、ISO 15924；首頁與語言選擇頁設定 x-default；CMS 自動化產生避免人工疏漏[S10][S8]。
